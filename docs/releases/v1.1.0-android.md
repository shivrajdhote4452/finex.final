* **Fail-Closed Build Configuration:** In [`mobile/android/app/build.gradle`](../../mobile/android/app/build.gradle), release builds fail closed via Gradle check if `key.properties` or release signing credentials are missing. Insecure fallback to debug signing is permanently removed.

### Important Installation Notice for Existing Users (Clean Reinstall vs. In-Place Update)

> [!IMPORTANT]
> **Users with the legacy `v1.0.0-android` APK installed MUST uninstall the app before installing v1.1.0.**
> 
> * **Why:** `v1.0.0-android` APKs were signed with the Android SDK auto-generated debug certificate (`CN=Android Debug`, SHA-256: `4652b7a3...`). Android OS enforces cryptographic signature matching for application updates. Attempting to install this new production-signed build over the legacy debug-signed build will fail with `INSTALL_FAILED_UPDATE_INCOMPATIBLE`.
> * **Data Safety:** Cloud user records, portfolio holdings, cash balances, and trade orders remain securely preserved in PostgreSQL and are immediately restored once the user signs back in.
>
> **Users with a production-signed build (`v1.0.1` or later) can upgrade in-place** without uninstalling, as the signing certificate and version codes are strictly monotonically compatible.

## 2. Release Summary & Parity Changes (PR #47)

Version 1.1.0 achieves complete mobile authentication parity with the FinEx web terminal:

1. **Dual Authentication Support:**
   - Native "Continue with Google" with vector `GoogleLogo` (stripped internal developer notes such as "REQUIRES OAUTH").
   - Email and password **Sign In** and **Create Account** directly on mobile.
2. **Account Recovery & Unverified Account Handling:**
   - **Forgot Password?** flow dispatching password recovery instructions via email.
   - Contextual error banners detecting HTTP 403 unverified accounts with a 1-tap **"Resend verification link →"** CTA.
3. **Pure Black Terminal UI (`#000000`):**
   - FinEx dark theme styling with graphite panels (`#161616`), warm amber accent (`#F29A60`), mint green success (`#7AE8C4`), and soft red error (`#FFA292`).
   - Scrollable `SingleChildScrollView` layout verified on viewports down to 320px width without `RenderFlex` clipping.
4. **Single-Identity Account Linking:**
   - Google and Email/Password authentications sharing the same verified email address automatically link to the identical PostgreSQL user record, portfolio, orders, and virtual cash balance.
5. **Browser-Based Verification Requirement:**
   - Because `AndroidManifest.xml` does not configure custom URL schemes or Android App Links, email verification and password reset links route to the web terminal.
   - The mobile UI explicitly instructs users to open the verification or reset link in their mobile browser, then return to the FinEx app to sign in.

## 3. Version-Code Strategy & Downgrade Prevention

To prevent `INSTALL_FAILED_VERSION_DOWNGRADE` when users switch between Universal and ABI-specific APKs across releases, FinEx employs a **10,000-block tiered version code scheme**:

$$\text{versionCode} = \text{baseVersionCode} + \text{abiOffset}$$

For v1.1.0, the base version code is set to **`10003`**:

| APK Variant | Architecture | Base Code | ABI Offset | Final `versionCode` | Comparison vs. All v1.0.x APKs |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **`finex-universal-compressed-release.apk`** | Multi-ABI (`arm64`, `armeabi`, `x86_64`) | `10003` | `+0` | **`10003`** | **`10003 > 4002 > 2002 > 1002 > 2`** ✅ Can upgrade over ANY v1.0.x build |
| **`app-armeabi-v7a-release.apk`** | 32-bit ARM (`armeabi-v7a`) | `10003` | `+1000` | **`11003`** | **`11003 > 1002 > 1`** ✅ |
| **`app-arm64-v8a-release.apk`** | 64-bit ARM (`arm64-v8a`) | `10003` | `+2000` | **`12003`** | **`12003 > 2002 > 2001`** ✅ |
| **`app-x86_64-release.apk`** | 64-bit Intel/AMD (`x86_64`) | `10003` | `+4000` | **`14003`** | **`14003 > 4002 > 4001`** ✅ |

Future releases increment the base block (e.g. `v1.2.0` will use base `20001` $\rightarrow$ Universal `20001 > 14003`), guaranteeing that every variant of a new release is higher than all variants of preceding releases.
